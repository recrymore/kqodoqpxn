# Gift Radar V8.6 — обновление поиска

Замените app.py, gifts.py, see_api.py, index.html, test_see_api.py; добавьте test_history.py. Остальные файлы и Secrets оставьте. Остановите прежний Workflow и запустите Tracker Bot V8 test.

- `/count 25` задаёт размер подборки (в режиме владельца 1–50; в обычном режиме 1–10). В меню есть «Размер подборки». Выбор в Mini App сохраняется при запуске поиска.
- `/resetseen` очищает только свою историю.
- SQLite хранит идентификатор пользователя бота, идентификаторы уже сформированных NFT и время выдачи: до 1000 записей на пользователя, до 7 суток. Контакты владельцев не сохраняются. Поиск не повторяет эти NFT в течение срока хранения.
- В тестовом режиме владельца следующая страница источника запрашивается по cursor, если в кэше недостаточно новых подарков. Не более одной новой страницы за действие. Кэш живёт 5 минут. При исчерпании квоты или редких фильтрах выдача может быть меньше выбранного количества.
- SQLite сохраняет память при перезапуске процесса с тем же DB_PATH. Новый GitHub-hosted runner обычно получает чистую файловую систему; для памяти между такими запусками требуется постоянный диск хостинга (например, DB_PATH=/data/tracker.sqlite3 на подключённом томе).
- Интеграция API остаётся только в диагностическом режиме владельца, без фонового сканирования или массовой выгрузки контактов. Публичное использование требует согласования условий источника.
- Проверка: python -m unittest discover -q (50 локальных тестов; сетевые обращения в тестах подменены).
