Gift Radar V8.8 — выборка по разным диапазонам номеров и индивидуальная проверка

Загрузить файлы из архива в корень существующего репозитория V8.6/V8.7. Workflow и Secrets не изменять. После обновления остановить старый запуск и запустить Tracker Bot V8 test.

В тестовом режиме владельца (8677315356) поиск без фильтров из бота и Mini App использует SEE_API_KEY на сервере. До трёх страниц по документированным параметрам number_from/number_to, диапазоны 1–999, 1000–99999 и 100000–1000000. В каждом диапазоне старт выбирается случайно, результаты перемешиваются и распределяются по диапазонам. Это не равномерная выборка всей базы. При пустых диапазонах, редких совпадениях, ограничении источника или исчерпании квоты может быть меньше подарков. Сохранена память slug в SQLite на 7 суток, до 1000 записей на пользователя; GitHub Actions не обеспечивает сохранение базы между запусками.

В индивидуальной проверке /gift Slug-N и отдельной форме «Проверить одну NFT» в Mini App показывается публичный владелец, если API подтверждает публичность и возвращает корректный username. Только в этом режиме показывается кнопка ЛС, ведущая на публичный профиль, рядом с кнопкой «Подарок». Telegram сам определяет доступность чата. В массовых подборках только ссылки на подарки и копирование. Данные владельцев не сохраняются в историю или кэш и не рассылаются в группы. Указание источника сохранено в описании бота и внизу Mini App (в группе и при неудаче обновления описания — в тексте сообщения без предпросмотра).

API остаётся в режиме владельца; публичное использование нужно согласовать с поставщиком. Бесплатная квота проверяется перед каждым новым запросом. Скрытых владельцев не раскрывает. Локальные проверки используют подменённые сетевые ответы; реальный запуск с токеном и отображение на iPhone не проверены.
