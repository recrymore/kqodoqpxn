# Gift Radar — V4
Бесплатный Telegram Mini App. Вступление в группу обязательно для случайного поиска. Без платных подписок, API ID, API Hash, Telethon, Kurigram и пользовательских сессий.

## GitHub Actions — временный тест
1. Замените `app.py`, `index.html`, `test_app.py`, `README.md`, `requirements.txt`; добавьте `gifts.py`, `.gitignore`. Создайте `.github/workflows/bot.yml` из архива (или замените старый workflow). Старые `bot.py`, `core.py`, `test_core.py` из V1 не используются V4; их можно убрать. Не запускайте одновременно старый и новый workflow.
2. Secrets: `BOT_TOKEN`; владелец фиксирован в коде: 8677315356. Не публикуйте токен в коде.
3. Добавьте бота администратором в группу, указанную приглашением https://t.me/+DxLz5PTGdiRlZjVi. В группе отправьте `/groupid@имя_бота` от администратора с ID 8677315356 (не анонимно). Для этого можно сначала запустить workflow без `GROUP_ID` — поиск будет закрыт.
4. Создайте секрет `GROUP_ID` со значением, которое вернул бот, включая минус. Ссылка-приглашение не заменяет числовой ID. Остановите первый workflow, запустите заново.
5. Actions → Tracker Bot V4 test → Run workflow. Откройте бота `/start`, вступите в группу, нажмите «Проверить» и «Найти подарки». Повторно проверьте выход из группы. Поиск проверяет участие при каждом запросе; ошибки Telegram закрывают доступ.
6. `/admin` — настройка баннера, названия, приветствия, кнопки запуска, контакта поддержки; `/reply номер текст` — ответ на обращение.

Actions и временный Cloudflare Tunnel — только для ограниченного по времени интеграционного теста, не постоянный хостинг. При перезапуске адрес, локальные настройки и SQLite могут быть потеряны. Для постоянной работы используйте HTTPS-хостинг с постоянным диском. Остановите тест после проверки.

## Локальный запуск
`python -m unittest test_app -v`; `python app.py` — просмотр интерфейса без бота на http://127.0.0.1:8000. Для интеграции задайте переменные `BOT_TOKEN`, `GROUP_ID`, `WEBAPP_URL` (HTTPS), при необходимости `HOST`, `PORT`, `CONFIG_PATH`, `DB_PATH`. Без `GROUP_ID` поиск заблокирован. Ссылка группы по умолчанию задана выше, переопределяется `GROUP_URL` (HTTPS t.me/+...).

## Поиск
Случайная выборка из ограниченных диапазонов номеров четырёх коллекций (Plush Pepe, Jelly Bunny, Lush Bouquet, Precious Peach). Сервер проверяет публичную карточку `https://t.me/nft/<slug>` и возвращает только модель, фон, символ, выпуск, название, номер и ссылку на подарок. Не гарантирует, что подарок продаётся; нет автоматических рыночных цен, поиска всех коллекций, личных контактов, скрытых владельцев и хранения их идентификаторов. Запросы ограничены по частоте, кешируются в памяти, HTTP 429 обрабатывается ожиданием Retry-After. Если Telegram меняет HTML или ограничивает выдачу, поиск возвращает ошибку или неполную подборку. SQLite используется для обращений поддержки.

Локальные тесты имитируют Telegram API и HTML карточки. Реальный запуск с токеном и доступ к публичным страницам необходимо проверить на хостинге. Не передавайте личные данные в поддержку без необходимости.

## Режимы V4
- В чате `/start` открывает inline-меню после проверки участия. Случайная подборка и фильтры доступны также в Mini App.
- `/find collection=PlushPepe; model=Steel; backdrop=Black; symbol=Star` — любые поля необязательны, регистр не важен для атрибутов. Ограниченная случайная выборка, не полный индекс.
- По цене: до 5 TON, 5–20 TON, 20–999.999 TON, все. Источник — вручную заполненный каталог, пустой при первом запуске. Владелец добавляет `/lot PlushPepe-123 4.5` (пример синтаксиса, не реальная цена) и удаляет `/unlot PlushPepe-123`. Запись действует 24 часа; статус продажи и цена не подтверждаются автоматически.
- Результаты — ссылки на карточки NFT, не контакты владельцев. Нет отбора по опытности людей.
