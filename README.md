# Peek market check
Дополнение к V6: скопируйте peek_check.py в корень репозитория, а .github/workflows/peek-check.yml — в соответствующую папку. Старые файлы не заменяйте.
Actions → Peek market check → Run workflow → Check public market interface.
Тест открывает публичную страницу один раз, проверяет видимость известных надписей рыночных фильтров и останавливается. Не использует токены, аккаунты, cookies от пользователей, не обходит авторизацию, не считывает карточки, данные владельцев или контакты. Успешный тест не подтверждает наличие разрешения на автоматическое получение цен или доступность самих цен. Перед интеграцией нужно проверить условия использования и разрешение источника.
