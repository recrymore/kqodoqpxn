# Трекер подарков — версия 2

Telegram Mini App и отдельный бот. Python 3.10+, без сторонних библиотек, без Telethon/Pyrogram, API ID, API Hash, номера телефона и сессий личного аккаунта. Используется только Bot API и подписанные данные Telegram Mini App.

## Просмотр без бота
Открой `index.html` либо запусти `python app.py` и перейди на http://127.0.0.1:8000. Без токена доступен только интерфейс. Цены не заданы, демонстрационный баннер можно изменить после запуска бота.

## Запуск в Telegram
1. Создай бота через @BotFather и сохрани токен в секрете.
2. Подготовь хостинг Python с HTTPS-доменом и постоянным диском. Для своего reverse proxy направь домен на локальный порт 8000.
3. Задай переменные окружения сервера:

```sh
export BOT_TOKEN='ТОКЕН_ОТ_BOTFATHER'
export ADMIN_IDS='ТВОЙ_ЧИСЛОВОЙ_TELEGRAM_ID'
export WEBAPP_URL='https://твой-домен'
export HOST='127.0.0.1'
export PORT='8000'
python app.py
```

Для хостинга с собственным TLS, которому нужно прослушивание всех интерфейсов, установи HOST=0.0.0.0. Запускай один экземпляр polling, без одновременного webhook. Не публикуй токен. Сохраняй config.json и tracker.sqlite3 на постоянном диске (переменные CONFIG_PATH и DB_PATH позволяют выбрать путь). Существующий config.json совместим с новой версией.

## Управление
/start — открыть трекер. /admin — административное меню, доступное только ID из ADMIN_IDS. Можно изменить название, верхний баннер и его видимость, приветствие, подпись кнопки запуска, сроки и цены в GRAM, контакт поддержки и реферальный бонус. Тарифы вводятся строками `дни цена`, например `1 100`. Это пример, не установленная стоимость. Обновление конфигурации Mini App — раз в 5 секунд.

## Поддержка
В Mini App можно отправить текстовое обращение, увидеть историю и ответ. Администратор получает уведомление, может открыть очередь через /tickets или кнопку «Обращения» и ответить `/reply 1 Текст ответа`. Ответ хранится в SQLite и появляется в Mini App, бот также пытается доставить его пользователю. Отправка требует валидного Telegram initData; срок авторизации — 24 часа, затем нужно открыть приложение заново. Ограничение — 5 обращений на пользователя в час. Скриншоты пока не подключены.

## Проверки
`python -m unittest -v` — локальные тесты подписанных данных, тарифов и сохранения настроек, прав администратора, изоляции обращений и ответа. Проверка JS: node --check для извлечённого скрипта. Реальный Bot API, хостинг и интерфейс на iPhone ещё не проверялись.

## Что не подключено
Поиск, лента, мониторинг подарков, статистика, рефералы, промокоды, пользовательский API, дополнительные боты, выдача подписки и реальные платежи. Кнопка оплаты — макет, транзакций не создаёт. Пробного периода нет. Для цифровых услуг внутри Telegram действуют правила оплаты через Stars; оплата GRAM не реализована. Функции, требующие доступа к данным личного аккаунта, не заменяются Bot API автоматически.
