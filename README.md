# Gift Radar — V6
Бесплатный Telegram Mini App и бот на Bot API. Без API ID, API Hash и личных сессий. Обязательная подписка на https://t.me/ZergowNft. Владелец: 8677315356.

## Установка через GitHub
1. Замените файлы из архива в корне репозитория, включая `.github/workflows/bot.yml`. Старые файлы `bot.py`, `core.py`, `test_core.py` из ранних версий не используются. Не запускайте одновременно два workflow с одним токеном.
2. Settings → Secrets and variables → Actions: добавьте `BOT_TOKEN`. `GROUP_ID` и `ADMIN_IDS` больше не нужны: канал и владелец заданы в коде. Не публикуйте токен.
3. Добавьте своего бота администратором в @ZergowNft. Проверка `getChatMember` требует прав администратора для надёжной работы. Это обязательный канал, а не место рассылки результатов.
4. Actions → Tracker Bot V6 test → Run workflow. Откройте бота командой `/start`. Проверьте подписку и запустите поиск. Если проверка недоступна, проверьте права бота в канале.
5. Workflow создаёт временный HTTPS Cloudflare Tunnel на 30 минут. После завершения адрес, SQLite и конфигурация на диске runner могут исчезнуть. Для постоянного запуска используйте HTTPS-хостинг с постоянным диском.

## Доставка подборок
- По умолчанию результаты из чата и Mini App отправляются одним сообщением в личный чат с ботом. Mini App также отображает карточки на экране.
- В боте выберите «Куда присылать NFT» (или `/delivery`). В Mini App: Настройки → Куда присылать NFT. Нажмите «Подключить группу».
- Создайте группу самостоятельно в Telegram, добавьте бота администратором. От своего имени, не анонимно, отправьте команду `/connect@имя_бота КОД`, которую выдаст бот. Код действителен 10 минут, одноразовый и привязан к ID запросившего пользователя. Подключить обязательный канал @ZergowNft как место доставки нельзя. Бот сам группы не создаёт.
- Один пользователь — одна выбранная группа. Можно переподключить другую. В группе будут только сообщения с подарками, без кнопок управления поиском. Перед доставкой проверяются обязательная подписка и права пользователя и бота в группе. Если доставка в группу не подтверждена, бот пытается отправить подборку в личный чат (при сетевой неопределённости возможен дубль). Для возврата к личному чату нажмите «В личный чат» или `/private`.
- Бот публикует результаты только по запросу пользователя, не ведёт постоянную фоновую рассылку. Привязка хранится в SQLite. Для работы в личном чате сначала откройте бота через `/start` и не блокируйте его.

## Поиск и ограничения
Случайная выборка (1–10 карточек) из ограниченных диапазонов четырёх коллекций Plush Pepe, Jelly Bunny, Lush Bouquet и Precious Peach. `/find collection=PlushPepe; model=Steel; backdrop=Black; symbol=Star` — фильтры по публичным атрибутам. Источник: публичные карточки `t.me/nft/...`, а не полный рынок. По цене — до 10 карточек из вручную заполненного каталога; реальные рыночные цены и наличие продажи автоматически не проверяются. Нет обхода скрытия владельца, сбора контактов и отбора людей по опытности. При ограничении источника поиск возвращает ошибку или неполную выборку. В чате размер по умолчанию — 10; в Mini App — от 1 до 10. Поиск ограничен временем (40 секунд между началом и последней попыткой; текущий запрос может занять ещё до 8 секунд) и числом попыток, при ограничении источника новые запросы прекращаются.

## Админ-панель
`/admin` — название, баннер, приветствие, кнопка запуска, контакт поддержки, текст просьбы о подписке. `/lot PlushPepe-123 4.5` — пример добавления цены в каталог на 24 часа; `/unlot PlushPepe-123` — удалить. `/reply номер текст` — ответ в поддержку. Пользовательские группы не дают права администрирования трекера.

## Локальный запуск
`python -m unittest test_app -v`; `python app.py` для предпросмотра без токена (http://127.0.0.1:8000). Для интеграции: `BOT_TOKEN`, `WEBAPP_URL` (HTTPS); опционально `HOST`, `PORT`, `DB_PATH`, `CONFIG_PATH`. Тесты имитируют Bot API и карточки. Реальная доставка и проверка канала требуют запуска с токеном. Фотография встроена в `index.html`.
