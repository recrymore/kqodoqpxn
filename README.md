# NFT Gift Parser

Поиск подарков через Telegram-бота: каталог, отдельный Telegram Market, фильтры по коллекции, модели, фону, узору, номеру, цене и редкости, сортировка, 10 результатов на страницу. База SQLite. Каталог включает замеченные лоты и NFT, добавленные по ссылкам, независимо от продажи; не является полным каталогом всех NFT Telegram.

## Запуск (Python 3.10+)
1. Создай бота в @BotFather, получи токен. Получи API ID и API hash на https://my.telegram.org/apps для своего аккаунта.
2. Распакуй архив. В терминале открой папку `gift_parser`.
3. `python -m venv .venv`
4. Windows PowerShell: `.\.venv\Scripts\Activate.ps1` ; Linux/macOS: `source .venv/bin/activate`.
5. `python -m pip install -r requirements.txt`
6. Скопируй `.env.example` в `.env` и заполни три секрета. Не отправляй их другим людям. Не передавай файл `market.session`.
7. `python bot.py` — при первом запуске Telethon попросит номер, код и пароль 2FA (если настроен) в локальном терминале. Используй действующий аккаунт с разрешённым доступом; не пытайся обходить блокировку аккаунта.
8. Открой своего бота, отправь `/start`. Для непрерывного сканирования процесс должен работать.

## Особенности
- Market: официальный `payments.getResaleStarGifts` (требует пользовательскую сессию). Каталог коллекций — `payments.getStarGifts`.
- Сканирование ограничено `MAX_PAGES_PER_COLLECTION` за проход; на крупных коллекциях выдача неполная. По умолчанию 10 страниц по 50 лотов. `GIFT_IDS` можно задать через запятую для нужных коллекций. Сканирование уважает FloodWait; частоту не повышай для обхода ограничений. Цена и наличие — снимок, а не гарантия. Лоты старше MARKET_TTL не попадают в Market. При полном проходе исчезнувшие лоты очищаются; при частичном — нет до истечения TTL. Новизна в сортировке — время обновления записи, не дата создания NFT.
- В каталоге можно добавлять отдельные NFT по ссылке (официальный `payments.getUniqueStarGift`). Фильтры текстовые, точные названия; есть выбор из уже собранных значений. Редкая модель — известная численная редкость ≤1%; неизвестная редкость не включается. Цена — только в выбранной валюте, без конвертации.
- Контакт: владелец сам отправляет ссылку через кнопку «Мой подарок: открыть контакт». Согласие истекает через 24 часа, отзыв доступен сразу. Перед отображением бот сверяет текущего владельца и username в свежем ответе Telegram. Если сервер не выдаёт ID или username, контакт не показывается. Бот не сохраняет данные владельцев без согласия, не собирает телефоны, пол, онлайн-статус и не отправляет личные сообщения. Уже отправленные сообщения Telegram отзыв согласия не удаляет.
- Для полного сканирования рынка потребуется оценить ограничения API на реальном аккаунте. Код не проверен с живым Telegram: токены и сессия не предоставлены. Локальные тесты проверяют базу, фильтры, парсинг, а не сеть или совместимость всех версий TL.
